# v0.2.0 驗證紀錄（2026-10-22）

- Blender 5.1.1 背景模式建立角色，保留 `.blend`、重建 Python、GLB 與 Cycles 預覽。未連線或修改使用者既有 Blender 視窗。
- 118 個零件；55 組連接的邊界重疊檢查通過，模型 mesh 旋轉／縮放已套用。完整資料見 `models/geometry-audit.json`。這是幾何組裝檢查，並非單一封閉流形或實體列印認證。
- 牛、牛仔 GLB 為內嵌資源；測試確認命名節點、沒有外部 buffer 或必要解碼器依賴、每個模型小於 50,000 三角面及 2 MB。
- `npm test`：14/14 通過。包含新增 3 項資產／幾何測試，以及既有 11 項物理、幀率、暫停與感測器模擬測試。
- 實際 IAB 預覽：桌面 1280×720；iframe 模擬 390×844、320×568、844×390。這是瀏覽器尺寸驗證，不是實體手機測試。
- 實際流程：載入、觸控入口、倒數、未操作摔落、結算、再騎一次、暫停、繼續、回到起點。Console 沒有新錯誤或警告。
- 摔落攝影機保留角色落點，牛仔包圍盒不穿過地面。
- 保留舊版程式角色作為資產載入失敗備援；載入中按鈕 disabled，失敗提示可重新整理。沒有以斷網逐項測試。
- 手機陀螺儀授權、實際傾斜方向與觸感尚未實機驗證；需要有效 HTTPS。未部署公開網站。
