# 手機終結者配音

生成日期：2026-10-22。模型 google/gemini-3.8-flash-tts；聲線 Algenib。使用 OpenRouter audio/speech，台羅輸入與角色 prompt 見根目錄 voice_lines.json。原始 PCM 24kHz mono 經剪頭尾靜音、等化、壓縮與限制峰值後轉為 96k MP3。無背景音樂；電子配樂由 audio.js 即時產生。

intro 開場；again 第二階段；trick 第三階段；wild 第四階段；final 第五階段；lose_air / lose_rest 輪流摔落吐槽；win 通關。

配音為合成角色，非真人錄音。一般播放只載入本地 MP3，無 API 呼叫。
